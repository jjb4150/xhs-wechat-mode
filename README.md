# 小红书微信模式（油猴脚本）

把小红书网页版首页变成微信式左右分栏界面：左栏是笔记"会话列表"，右栏以聊天气泡形式阅读笔记正文和评论，支持发送评论、点赞、收藏。

改造自 [Chiphell 微信模式](https://greasyfork.org/zh-CN/scripts/590132) 的 UI 架构，数据层针对小红书重写。

## 安装（Tampermonkey）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击扩展图标 → 添加新脚本
3. 删除编辑器里的模板内容，把 `xhs-wechat-mode.user.js` 全部内容粘贴进去
4. `Ctrl + S` 保存
5. 打开 https://www.xiaohongshu.com/explore 并确保已登录，界面会自动变成微信模式

## 使用

| 操作 | 说明 |
|---|---|
| 点击左栏笔记 | 右栏加载笔记正文（气泡）+ 评论 |
| 滚动左栏到底 | 自动加载更多笔记（驱动原页面无限滚动） |
| 搜索框 | 过滤当前已加载笔记的标题/作者 |
| 底部输入框 | 发送评论（Enter 发送，Shift+Enter 换行） |
| ♥ / ★ | 气泡下方或右上角点赞、收藏 |
| 展开 N 条回复 | 加载楼中楼全部回复 |
| 点击笔记图片 | 打开大图查看器（←/→ 切换，Esc 关闭） |
| 拖动分隔条 | 调整左栏宽度（双击还原） |
| 油猴菜单 | 启用/停用微信模式 |

## 技术方案

- **feed 列表**：扫描页面 `.note-item` DOM + MutationObserver，页面滚动自动加载新卡片
- **笔记正文**：`fetch` 笔记页 HTML → 解析内嵌 `__INITIAL_STATE__` JSON（无需破解接口签名）
- **评论/点赞/收藏/发评论**：隐藏 iframe 加载真实笔记页，读取其 DOM / 驱动其真实控件（零伪造请求，不易触发风控）

## 已知限制（v0.1.0）

- 仅首页"发现" feed 启用；搜索页、个人主页保持原样
- 视频笔记只显示封面图，暂不支持播放
- 点赞/收藏按钮在个别笔记类型上可能定位失败（会提示改用"原页"操作）
- 楼中楼需要先点"展开 N 条回复"才能看到全部

## 开发

```
demo.html   # UI 静态预览页（python -m http.server 后浏览器打开）
demo.css    # 从脚本提取的样式，改样式后需同步回脚本内的 CSS 常量
xhs-wechat-mode.user.js  # 主脚本（单文件，无构建）
```

调试：F12 控制台过滤 `[小红书微信模式]` 查看运行日志。
